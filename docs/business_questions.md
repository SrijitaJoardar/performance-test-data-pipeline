# Business Questions

Our pipeline should answer questions such as:
1. What is the average response time for each API endpoint?
2. What are the p50, p95, and p99 response times for each test run?
3. Which endpoints have the highest error rates?
4. Did response time increase or decrease between two builds?
5. Which build introduced a performance regression?
6. How did throughput change across test runs?
7. Which endpoints are consistently slow across multiple builds?
